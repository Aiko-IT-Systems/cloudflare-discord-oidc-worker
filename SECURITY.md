# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| > 3.0   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to the maintainers by sending an email to `support@aitsys.dev` or using the [GitHub Security Advisories](https://github.com/aitsys/discord-oidc/security/advisories).
